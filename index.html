Capítulo 01

Conceptos Clave

Vector embeddings, similaridad coseno, RAG.

1. ¿Qué es un vector embedding?

Un vector embedding es una representación numérica densa de texto que captura su significado semántico. Por ejemplo, la frase "El gato está en el tejado" podría representarse como un vector de 384 dimensiones (p. ej. [-0.12, 0.45, ..., 0.08]).

2. Similaridad coseno

La similaridad coseno mide el ángulo entre dos vectores. Valores cercanos a 1 indican alta similitud semántica. Por ejemplo:

Python — Similaridad coseno 
from sklearn.metrics.pairwise import cosine_similarity

embedding1 = [-0.12, 0.45, ..., 0.08]  # "El gato está en el tejado"
embedding2 = [0.08, 0.42, ..., -0.05]  # "El perro está en el tejado"

similarity = cosine_similarity([embedding1], [embedding2])[0][0]
# similarity ≈ 0.85 (alta similitud)

3. RAG (Retrieval-Augmented Generation)

RAG combina recuperación de embeddings con generación de lenguaje. Primero recupera documentos relevantes y luego los usa como contexto para generar respuestas.

Capítulo 02

Generación de Embeddings

Modelos como all-MiniLM-L6-v2, parámetros, normalización.

1. Modelos populares

  • all-MiniLM-L6-v2: ligero (384 dimensiones), balance entre rendimiento y tamaño.
  • text-embedding-ada-002: de OpenAI, alto rendimiento (1536 dimensiones).
  • multilingual-e5-large: multilingüe, 1024 dimensiones.

2. Parámetros de generación

Parámetro Valor típico Propósito
normalize_embeddings True Normaliza los vectores a longitud 1 para comparaciones coseno.
batch_size 32 Procesa múltiples textos en paralelo.
trust_remote_code False Evita ejecución de código remoto no verificado.

3. Ejemplo de generación

Python — Generación con Sentence Transformers 
from sentence_transformers import SentenceTransformer

model = SentenceTransformer('all-MiniLM-L6-v2')
embeddings = model.encode(
    ["El gato está en el tejado", "El perro está en el tejado"],
    normalize_embeddings=True,
    batch_size=32
)

# embeddings[0] ≈ [-0.12, 0.45, ..., 0.08]
# embeddings[1] ≈ [0.08, 0.42, ..., -0.05]

Capítulo 03

Almacenamiento de Embeddings

FAISS/Chroma, índices, particiones.

1. Librerías de almacenamiento

  • FAISS: de Meta, optimizado para búsqueda vectorial en memoria.
  • Chroma: base de datos vectorial ligera, con interfaz SQL.

2. Ejemplo de almacenamiento con FAISS

Python — FAISS 
import faiss
import numpy as np

# Crear índice FAISS
index = faiss.IndexFlatL2(384)  # 384 dimensiones

# Añadir embeddings
embeddings = np.array([[-0.12, 0.45, ..., 0.08], [0.08, 0.42, ..., -0.05]], dtype='float32')
index.add(embeddings)

# Guardar índice a disco
faiss.write_index(index, "embeddings.index")

3. Particiones y metadatos

Los embeddings suelen almacenarse con metadatos (fuente, fecha, categorías) para filtrar resultados. Por ejemplo:

JSON — Metadatos 
{
    "id": "doc_123",
    "text": "El gato está en el tejado",
    "embedding": [-0.12, 0.45, ..., 0.08],
    "metadata": {
        "source": "manual.txt",
        "category": "animales",
        "date": "2026-08-01"
    }
}

Capítulo 04

Recuperación de Embeddings

similarity_search, k-NN, filtros.

1. Búsqueda por similaridad

La recuperación de embeddings se hace mediante búsqueda de vecinos más cercanos (k-NN). Por ejemplo:

Python — FAISS 
# Cargar índice FAISS
index = faiss.read_index("embeddings.index")

# Buscar los 3 embeddings más similares
query_embedding = np.array([[0.15, 0.38, ..., -0.02]], dtype='float32')
D, I = index.search(query_embedding, k=3)

# I[0] = [1, 0, 2]  # índices de los documentos más similares
# D[0] = [0.12, 0.18, 0.25]  # distancias coseno (1 - similitud)

2. Filtros y particiones

Los metadatos permiten filtrar resultados. Por ejemplo, buscar solo documentos de la categoría "animales":

Python — FAISS con filtros 
# Filtrar por metadatos (requiere Chroma o implementación custom)
results = index.search(
    query_embedding,
    k=3,
    filter={"category": "animales"}
)

# results = [doc_123, doc_456, doc_789]
